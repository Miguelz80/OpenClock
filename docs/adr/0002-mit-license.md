# 0002. MIT license

- **Status:** Accepted
- **Date:** 2026-11-18

## Context

The project is meant to be free on GitHub so others can learn from it, contribute and build their own versions. The maintainer may monetize a hosted service later.

## Decision

License the code under the MIT license, as confirmed by the maintainer.

## Consequences

- Maximum adoption: anyone may use, modify and redistribute the code, including commercially, as long as the copyright notice is kept.
- Others may also run a competing hosted service without publishing their changes. Any monetization should therefore rely on the hosted service, convenience and support, not on keeping code exclusive.
- Third-party dependencies must have compatible licenses. Data obtained from platforms (Garmin, Apple, Meta) is governed by those platforms' terms, not by this license.
