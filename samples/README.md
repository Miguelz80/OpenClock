# Synthetic samples

Every file here is **fictional** and generated by [`openclock.synthetic`](../src/openclock/synthetic.py). No real person's data is included. Regenerate them with:

```bash
python -m openclock.synthetic samples/
```

A test (`test_demo_sample_is_reproducible_from_generator`) fails if a committed file drifts from the generator.

The demo week is **Monday 2026-11-16 to Sunday 2026-11-22 in `America/Sao_Paulo`** (UTC−03:00, no daylight saving time).

## `garmin_run_2026-11-17.fit`

A Garmin FIT activity file with one running session.

| FIT field | Value in file | Normalized |
|---|---|---|
| `file_id.serial_number` | `3999999901` (fictional) | part of `source_id` |
| `file_id.time_created` | 2026-11-17 09:30:00 UTC | part of `source_id` |
| `session.sport` | `running` | `running` |
| `session.start_time` | 2026-11-17 09:30:00 UTC | 2026-11-17 **06:30** in São Paulo |
| `session.total_timer_time` | 2710 s | duration **45:10** |
| `session.total_elapsed_time` | 2750 s | not used (includes pauses) |
| `session.total_distance` | 8420.00 m | **8.42 km** |

`source_id` = `3999999901-1794907800-s0` (serial, `time_created` as Unix seconds, session index).

To inspect the raw file yourself:

```bash
python -c "from garmin_fit_sdk import Decoder, Stream; print(Decoder(Stream.from_file('samples/garmin_run_2026-11-17.fit')).read()[0]['session_mesgs'])"
```
